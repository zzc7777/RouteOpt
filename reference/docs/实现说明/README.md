## 维护规则

- 以实际代码和可重复测试为准，不以需求或计划作为完成依据；
- 模块行为发生变化时，同一批修改必须更新对应实现说明；
- 每份说明应包含入口、文件职责、数据流、实际行为、验证方式和已知限制；
- 未实现内容只能写入“已知限制”或需求文档，不能描述成现有能力。
