## 状态和更新规则

- 文档状态统一使用：草案、待确认、已确认、实现中、已完成、已废弃。
- 同一主题只能有一个有效来源；旧文档必须删除或明确标记为已废弃。
- 文档索引只记录长期状态，不记录每次对话和完整终端输出。
