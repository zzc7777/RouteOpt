## 状态和更新规则

- 文档状态统一使用：草案、待确认、已确认、实现中、已完成、已废弃。
- 同一主题只能有一个有效来源；旧文档必须删除或明确标记为已废弃。
- 文档索引只记录长期状态，不记录每次对话和完整终端输出。
- 完成功能后，保留的事实进入 `实现说明/`，对应已完成需求从 `需求/` 删除。
- 每个已完成功能需有面向用户的流程与方法导读；较长时与简短模块说明分开并互链，后续行为变化时同步维护，具体规则见 `AGENTS.md`。
- 新增、删除、重命名或替代文档时，必须同步更新本索引。
